# 职前副本 AI - Image-first 复刻工作流

本目录仅服务于全新项目 `career-copy-ai-demo`，不修改工作区中的另一个 Demo。

## 执行顺序

1. `original/`：用户提供的 10 张原始页面参考图。
2. `page-generation-spec.md`：Taste Skill 约束下的 11 页独立参考图生成规范。
3. `generated-pages/`：已使用 Image Gen Skill 生成并保存 11 张新参考图。
4. `visual-assets.md`：从参考图中识别出的独立视觉素材及使用规则。
5. `generated-assets/`：最终用于前端的视觉素材；`*-v2.png` 为 Image Gen Skill 生成版本。
6. 前端只能依据参考图、视觉素材与本目录内的规格实现。

## 1:1 复刻边界

- 图片素材：数字分身、AI 机器人、岗位卡封面、作品封面、勋章和奖励插画。
- 代码绘制：文字、按钮、卡片、进度条、导航、表单、弹窗、图表、状态反馈。
- 禁止把整页参考图作为页面背景或用图片热点伪造交互。
- 所有导航、筛选、弹窗、提交、下一题、评分更新均由 React state 驱动。
- 页面基准尺寸为 `1448 x 1086`，同时支持更宽桌面自适应。
